# 🚀 Bienvenue sur le Wiki 3LEvent

Bienvenue sur la **documentation officielle des développeurs** pour le projet **3LEvent**. Ce site centralise toutes les ressources techniques, les guides d'installation et les protocoles de l'organisation.

---

## 🎯 Notre Mission

Ce Wiki a pour but de permettre à chaque membre de l'équipe technique de :
* **Comprendre** l'architecture globale de nos services.
* **Installer** et configurer les environnements de développement rapidement.
* **Contribuer** de manière sécurisée et structurée au code source.

> [!IMPORTANT]
> L'accès à ce site est protégé par **Cloudflare Zero Trust**. Seuls les membres autorisés de l'organisation 3LEvent peuvent consulter ces pages.

---

## 🛠️ Stack Technique

Le Wiki est propulsé par des outils modernes pour garantir une maintenance facile :
* **Framework** : [Docusaurus v4](https://docusaurus.io/).
* **Hébergement** : GitHub Pages.
* **Déploiement** : GitHub Actions.
* **Sécurité** : Cloudflare Access.

---

## ✍️ Comment contribuer ?

### 1. Structure des branches
* **`main`** : Branche de production (`doc.3levent.fr`).
* **`develop`** : Branche de travail et de brouillon.

### 2. Processus de modification
1. Faites vos changements sur **`develop`**.
2. Vérifiez le rendu localement : `npm run start`.
3. Ouvrez une **Pull Request** vers `main`.
